# Chuxmart

An online game exchange where players can pass along games they no longer use.

## Architecture

See the [project architecture diagram](docs/architecture.md) for the current
browser, build, and static-hosting flow.

## Run locally

```sh
npm install
npm run dev
```

The sign-in page is a front-end demo. Authentication, password recovery, account
creation, and the linked legal pages are not connected to a service yet.

## Build

```sh
npm run build
```
